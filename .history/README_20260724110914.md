# WEG Warehouse. Projeto-base

Projeto-base estático para a recuperação da avaliação prática de Next.js.

## Estrutura

- `/`: painel com indicadores e 24 posições mockadas diretamente no HTML.
- `posicao.html`: página única genérica, usada por todos os links do mapa.
- `sobre.html`: página institucional estática.
- `assets/img/logo-weg.png`: logotipo usado na interface.

## Objetivo da avaliação

Os estudantes deverão converter a interface para Next.js, criar componentes reutilizáveis, consumir a API real, implementar filtros, gerar o mapa dinamicamente e criar uma rota dinâmica para os detalhes de cada posição.

## Execução

Abra `index.html` no navegador. Como o Tailwind é carregado por CDN, é necessário acesso à internet para visualizar os estilos.
