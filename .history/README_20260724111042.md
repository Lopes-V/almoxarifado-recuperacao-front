# WEG Warehouse. Projeto-base

Projeto-base estático para a recuperação da avaliação prática de Next.js.

## Estrutura

- `/`: painel com indicadores e 24 posições puxadas da api.
- `/posicao/id`: página única, usada por todos os links do mapa.
- `/sobre`: página institucional estática.
- `public/logo-weg.png`: logotipo usado na interface.

## Objetivo da avaliação

Os estudantes deverão converter a interface para Next.js, criar componentes reutilizáveis, consumir a API real, implementar filtros, gerar o mapa dinamicamente e criar uma rota dinâmica para os detalhes de cada posição.

## Execução

rode npm install, após isso de um npm run dev e utilize o sistema
